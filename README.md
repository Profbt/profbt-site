## Overview

This repository contains Bruno Carvalho's professional website. It presents selected projects and services across full-stack development, artificial intelligence, workflow automation, education, technical training, IT infrastructure, and geospatial technologies.

The site is deliberately framework-free. It can be served as static files, requires no client build process, and remains straightforward to maintain and deploy.

## Goals

- Present a clear international professional positioning.
- Provide direct access to selected public projects and demonstrations.
- Keep performance, accessibility, and maintenance costs low.
- Separate the professional portfolio from the student resource center.
- Support search-engine discovery through `robots.txt` and `sitemap.xml`.

## Architecture

```text
profbt-site/
├── index.html
├── robots.txt
├── sitemap.xml
├── DEPLOY.md
└── assets/
    ├── css/styles.css
    ├── js/app.js
    ├── img/
    └── icons/
```

## Run locally

Open `index.html` directly or start a local static server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

[English](#profbt--professional-portfolio) | **Português**

## Visão geral

Este repositório contém o site profissional de Bruno Carvalho. Ele apresenta projetos e serviços em desenvolvimento Full Stack, inteligência artificial aplicada, automação, tecnologia educacional, formação técnica, infraestrutura de TI e geotecnologias.

O projeto foi construído como site estático, sem framework e sem etapa obrigatória de build. Essa decisão mantém a publicação rápida, a manutenção simples e o baixo consumo de recursos.

## Objetivos

- Apresentar um posicionamento profissional claro e internacional.
- Facilitar o acesso a projetos públicos e demonstrações.
- Manter bom desempenho, acessibilidade e simplicidade de manutenção.
- Separar o portfólio profissional da Central dos Alunos.
- Apoiar a descoberta por buscadores com `robots.txt` e `sitemap.xml`.
